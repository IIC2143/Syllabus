# IIC2143 - Ingeniería de Software ✨

Bienvenidos al repositorio oficial del curso **IIC2143 - Ingeniería de Software**.

Este repositorio centraliza material público del curso, documentación, recursos complementarios y distintos elementos que utilizaremos a lo largo del semestre.

## 📣 Comunicación oficial del curso 

La principal vía de comunicación oficial del curso será **Canvas**, especialmente a través de los anuncios publicados por el equipo docente.

Sin embargo, este repositorio también forma parte de los canales oficiales del curso. En particular:

- Toda información publicada en los **Issues** por integrantes del equipo docente se considera información oficial.
- Aclaraciones de enunciados, correcciones, cambios menores, preguntas frecuentes y otras comunicaciones podrán ser publicadas mediante Issues.
- Los estudiantes son responsables de mantenerse informados respecto de los anuncios de Canvas y de la actividad relevante en este repositorio.

En caso de existir discrepancias, el equipo docente podrá publicar aclaraciones adicionales mediante Canvas o GitHub.

## 💻 ¿Por qué usamos GitHub?

La ingeniería de software moderna se desarrolla utilizando herramientas de colaboración. Durante el curso trabajaremos con tecnologías y flujos de trabajo ampliamente utilizados en la industria:

- Git
- GitHub
- Issues
- Pull Requests
- Revisiones de código
- Integración continua
- Automatización

Por esta razón, esperamos que los estudiantes se familiaricen con el uso cotidiano de estas herramientas.

## 🫡 Responsabilidad del estudiante

Es responsabilidad de cada estudiante:

- Revisar periódicamente Canvas.
- Revisar periódicamente este repositorio.
- Leer los anuncios publicados por el equipo docente.
- Mantener una comunicación fluida con su _product owner_ en lo que respecta al proyecto.

La falta de revisión de estos canales no constituye una justificación válida frente a cambios, correcciones o comunicaciones oficiales realizadas oportunamente.
